# 15 November 2026 — Setting up my cybersecurity notes

Today I created this public GitHub repository to keep my cybersecurity learning in one place.

I wanted a place for more than just tool names. When I practise something, I want to save the command, understand the output and write down where I got stuck. I also want to keep TryHackMe and Hack The Box notes separate from general topic notes.

## What I set up

- Folders for networking, Linux, reconnaissance, web security and Metasploit.
- Separate places for SOC/SIEM, privilege escalation and lab-platform notes.
- A daily notes folder and a monthly review template.
- A basic learning checklist so I can see which subjects I still need to practise.

## A rule for the journal

I had originally asked for the journal to cover dates from 1 June 2026. I don't have evidence for a cybersecurity study entry for every day since then, so I am not going to fill the missing dates with invented notes. The earlier November entries are recaps of topics from my learning conversations. Their dates describe the learning discussion, not a backdated Git commit.

I want the notes to stay honest. If I only read about a command, I'll say that. If I actually run it and get output, I'll record what happened.
