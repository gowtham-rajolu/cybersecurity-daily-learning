## Nmap command notes

```bash
# Scan selected ports on an authorized lab target
nmap -p 22,80,443 <lab-ip>

# Service/version detection
nmap -sV <lab-ip>

# Default scripts and version detection
nmap -sC -sV <lab-ip>

# Read authorized targets from a file
nmap -iL targets.txt
```

Use these only within the lab scope. `-sC` runs Nmap's default script set; inspect scripts and target impact before using them in a production engagement.

## Tool comparison

| Tool | Primary purpose |
|---|---|
| Nmap | Host discovery, port scanning, service enumeration |
| Wireshark | Packet capture and protocol analysis |
| Burp Suite | Intercepting proxy and web application testing |
| Metasploit | Modular penetration-testing and exploit validation framework |
| Metasploitable | Deliberately vulnerable practice target |

Metasploitable is not a tool like Nmap; it is a vulnerable operating system/application environment used as a target in a controlled lab.

## VPN troubleshooting checklist

```bash
ip -br addr
ip route
ip route get <lab-ip>
ping -c 4 <lab-ip>
ss -tulpn
```

A VPN interface being UP does not guarantee that the route to a lab target is correct. ICMP can also be blocked, so ping failure alone is inconclusive.

## Metasploit concepts

Metasploit contains auxiliary, exploit, payload, and post modules. Start by learning module metadata and options:

```text
msfconsole
help
search type:auxiliary
info <module>
show options
```

Understand a module and its potential side effects before running it, and use an isolated vulnerable lab.
