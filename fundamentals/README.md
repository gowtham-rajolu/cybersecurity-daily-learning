# Cybersecurity Fundamentals

## Core security objectives

- **Confidentiality:** only authorized parties can access information.
- **Integrity:** information remains accurate and is changed only by authorized processes.
- **Availability:** systems and data remain accessible when needed.

## Key vocabulary

| Term | Meaning |
|---|---|
| Asset | Something valuable that needs protection |
| Threat | A potential cause of harm |
| Vulnerability | A weakness that could be exploited |
| Exploit | A method or code that takes advantage of a weakness |
| Risk | Likelihood and impact of a threat exploiting a vulnerability |
| Control | A safeguard that reduces risk |

## Security domains

1. Governance, risk and compliance
2. Network and infrastructure security
3. Application and API security
4. Identity and access management
5. Endpoint and cloud security
6. Security operations and incident response
7. Digital forensics and threat intelligence

## Authentication vs authorization

- Authentication answers: **Who are you?**
- Authorization answers: **What are you allowed to do?**
- Accounting/auditing records what happened.

## Defense in depth

Use multiple independent controls: MFA, least privilege, patching, network segmentation, secure configuration, monitoring, backups, and incident response.
