## 1. Practice approach

For a beginner-friendly CTF room, I want to work through the target methodically:

1. Read the room brief and confirm the target is the machine assigned by TryHackMe.
2. Connect to the lab using the platform's supported VPN or AttackBox method.
3. Check my local network interface and confirm the lab connection is active.
4. Enumerate exposed services before choosing any further tests.
5. Keep a record of commands, useful output, errors and questions.
6. Try to solve each task independently before looking for hints.

## 2. Commands to keep handy

The following are generic examples. Replace the placeholder with the assigned lab IP and run them only against the authorized room machine.

```bash
# Confirm local interfaces and VPN address
ip addr

# Check basic reachability
ping -c 4 <TARGET_IP>

# Discover common TCP services
nmap -sC -sV <TARGET_IP>

# Save results for later review
nmap -sC -sV -oN room-scan.txt <TARGET_IP>
```

A failed ping does not necessarily mean the target is offline; some lab machines or networks may block ICMP. Nmap results should be interpreted as observations, not assumptions.
