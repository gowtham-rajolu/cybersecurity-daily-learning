## Concepts learned

### File upload security

An upload endpoint should not trust a filename or extension supplied by the client. Defenses include allowlisted formats, content validation, safe server-generated filenames, storage outside the web root, least-privilege permissions, size limits, malware scanning where appropriate, and preventing uploaded files from being executed.

### Python virtual environments

A virtual environment isolates project dependencies from the system Python installation.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
deactivate
```

On distributions that mark system Python as externally managed, use a virtual environment rather than forcing global package installation.

### grep basics

```bash
grep "error" app.log
grep -i "failed" auth.log
grep -n "login" app.log
grep -r "TODO" ./project
grep -E "401|403|500" access.log
```

- `-i`: case-insensitive matching
- `-n`: show line numbers
- `-r`: recursive search
- `-E`: extended regular expressions

## Defensive takeaway

A successful upload should not imply that uploaded content is executable. Separate storage from execution, validate server-side, and log upload events.
