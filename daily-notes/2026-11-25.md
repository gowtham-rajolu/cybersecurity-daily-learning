## 1. SSH command-line study

Reviewed SSH as a client-server protocol for encrypted remote administration, including authentication with passwords or key pairs, host-key verification, and common connection troubleshooting.

Verbose connection options:

```bash
ssh -v user@host
ssh -vv user@host
ssh -vvv user@host
```

- `-v` enables verbose diagnostics.
- `-vv` provides more diagnostic detail.
- `-vvv` provides maximum SSH client debugging detail.

Verbose output helps identify issues such as key selection, authentication failures, host-key problems and connection negotiation. It can contain usernames, host details and file paths, so review output before sharing it publicly.
